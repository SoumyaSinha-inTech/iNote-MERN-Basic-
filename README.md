# iNote 📝
iNote is my first MERN stack project — a simple and secure note-taking web application.

## Features
- User Signup & Login
- Create and save notes
- Edit existing notes & Delete notes
- Notes are stored in MongoDB
- Each user can access their own notes even after logging out and logging back in

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
